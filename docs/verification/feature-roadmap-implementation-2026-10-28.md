## 保留的范围与环境边界

- SMB / NFS 没有可用服务器，真实连接待提供测试环境；Windows NFS 依赖系统 NFS 客户端及匿名挂载配置。其他平台的网络映射不在当前实现内。
- 系统多文件拖拽已传递全部路径，但未向真实外部接收应用执行拖入验收。
- 默认应用管理遵循系统确认流程，本次未修改用户关联。系统入口依据 [Microsoft 默认应用设置文档](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings)；多文件拖拽依据 [Electron webContents API](https://www.electronjs.org/docs/latest/api/web-contents)。
- 图标文件写入 / 原始 ini 还原已测试，未实测 Explorer 的图标缓存刷新；macOS / Linux 只提供应用内自定义图标，不宣称已完成平台原生图标设置。
- 全文搜索是有界递归扫描，不含 OCR 或索引；单文件 32 MB，默认深度 64，最多扫描 100000 项、返回 5000 处匹配；每文件最多 10 处命中，PDF 最多提取 1000 页。不支持旧版 DOC / PPT 文本提取，Excel 的行号是提取文本行号。
- TAR / TGZ 是内存式处理，原始数据上限 1 GB；归档内符号 / 硬链接条目不支持；压缩目标存在时返回冲突，不静默覆盖。
- 操作时间线不包含外部应用的文件变更和历史版本快照；撤销栈为当前进程内的核心文件操作，不包含永久删除、归档、权限、标签、图标和网络设置。
- 原路线图的 AirDrop、BitLocker、系统 File History / Versions、云 Provider、密码归档、ZIP64、GBK 转码等跳过项继续保留。未执行安装包打包、跨平台桌面验收或性能基准测试。
- 已修正路线图的错误表格、陈旧测试数和 TypeScript 版本；核心文件 / 新工具 / 标签采用 `Result`，历史配置及窗口接口沿用旧契约，文档不再宣称所有 IPC 已全面迁移。
