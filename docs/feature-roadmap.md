## ⛔ 跳过 — 平台专属/成本过高

- AirDrop, BitLocker, File History, Home Group, 3D Objects(Windows专属)
- Versions, Spotlight集成, iCloud共享, Quick Look extensions(macOS专属)
- Cloud providers(OAuth+各SDK)
- 加密/密码解压(短期跳过,已有ArchiveEncrypted错误码占位)
- ZIP64(>4GB单文件)
- GBK文件名转码(WinRAR中文ZIP兼容) — 留v2

## 验证范围与后续环境验收

- Windows 本机验证；macOS / Linux 的本轮改动未进行桌面实测。网络映射和默认应用管理目前提供 Windows 实现，其他平台返回明确提示。
- SMB / NFS 的系统适配、参数、失败与断开逻辑通过受控测试；没有可用测试服务器，**真实连接验收待具备服务器后进行**。
- 多文件原生拖拽的参数传递和校验已通过测试，**尚未验证外部接收应用的实际拖入结果**。
- 文件关联通过系统设置页面确认；本轮未更改用户默认应用。文件夹图标文件写入 / 还原通过测试，Explorer 图标缓存刷新未做完整实测。
- 全文搜索为递归内容扫描，不建立索引、不含 OCR；单文件上限 32 MB，默认深度 64，最多扫描 100000 项 / 返回 5000 处命中，跳过符号链接并报告无法读取的项目。
- TAR / TGZ 为内存式处理，原始数据上限 1 GB；不支持归档内链接条目；压缩目标已存在时返回冲突。加密归档、ZIP64、GBK 转码继续按原计划跳过。
- 撤销不包括永久删除、归档、权限、标签、网络映射和图标设置；时间线不等同于 Windows File History / macOS Versions。

## 架构约束

- Electron 33.4.11 + Vite 5.4.21 + React 18.3.1 + TypeScript 5.9.3 strict（本次已安装版本）
- contextIsolation: true, 全OS访问走 `window.tabula.*`
- `Result<T>` discriminated union: `{ ok: true, data } | { ok: false, error }`
- Provider模式: `providers/{drive,trash,window,shell,archive}/`
- 核心文件操作、新增工具及标签接口用 `Result<T>` 返回业务失败，界面显示错误；历史配置 / 窗口等接口沿用现有返回契约，不将其宣称为已全面迁移。
